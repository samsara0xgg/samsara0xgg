### Hey, I'm Allen

I'm an AI agent developer based in Victoria, BC, Canada.

I build tools that take repetitive work off our hands.

If something slows me down, chances are I'll find a way to automate it — then build it and ship it.

My main project is [Jarvis](https://github.com/samsara0xgg/Jarvis), a personal voice assistant with a growing ecosystem of automation tools that help us get through the day with less friction.

I also made [TimeSink](https://github.com/samsara0xgg/timesink), a Mac menu bar app that shows where your day went, and [Yana](https://github.com/samsara0xgg/typeless-local), hold-to-talk dictation for Mac that runs speech recognition locally.

Mostly working with **Python, React, TypeScript, Swift, and SQL**.
